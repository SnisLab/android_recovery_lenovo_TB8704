# Dependency request template

Use this template when the recovery workstream needs a change from another repository.

```text
Dependency request:
Repository: <SnisLab/repository>
Required change: <precise change>
Reason: <why recovery needs it>
Expected interface/result: <what recovery expects afterwards>
Evidence: <links/files/logs supporting the request>
Blocking: <yes/no>
```

Do not implement cross-repository changes from this repository.
